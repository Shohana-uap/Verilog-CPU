&#x20;**Verilog CPU — Set 7**



A CPU design project implemented using Verilog HDL.



&#x20;**Modules**

\- Program Counter (PC)

\- Program ROM

\- Control Unit

\- Arithmetic Logic Unit (ALU)

\- Accumulator and R/Z Registers

\- Top-Level CPU Integration



**Development**

This project is being developed incrementally. Each module and its testbench will be added through separate Git commits.



**Language**

Verilog HDL
